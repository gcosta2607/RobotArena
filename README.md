# Nuggets Arena

Jogo de sobrevivência para a feira da escola.

## Jogar

https://gcosta2607.github.io/RobotArena/

Escolha sua unidade e dificuldade e entre na arena. Use WASD ou as setas para se mover e Shift ou Espaço para dar dash. As teclas e o volume podem ser ajustados nas configurações.

Cristais, skins e recordes ficam salvos no navegador de cada jogador. Esta edição da feira é individual; o multiplayer está desativado.

A versão publicada usa HTML, CSS e JavaScript e roda diretamente no GitHub Pages.
